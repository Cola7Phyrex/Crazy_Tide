# CrazyTide

CrazyTide 是一个以生物构筑、基地经营和领土远征为核心的单机策略游戏。本目录目前包含 MVP 阶段 1 的浏览器版本。

开发文档：

- `CrazyTide_MVP开发文档.md`：浏览器MVP实现记录与冻结基线；
- `CrazyTide_第二阶段开发文档_2026-07-25.md`：2026-07-25起的开发顺序、优先级与里程碑；
- `CrazyTide_游戏设计文档.md`：权威玩法设计；
- `内容数据表/`：游戏内容、字段定义与灵感收集入口。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 当前完成范围

- Vite + 原生 JavaScript 工程；
- 英文和数字使用 PT Mono，中文使用更纱黑体简体中文网页子集；
- 桌面三栏、平板双栏、手机单栏响应式布局；
- 基地与记录页面接入真实游戏状态；
- 五种法术力起源和五块初始基本地；
- 同色/异色开局资源、容量和每分钟产能；
- 亚空间残渣回收按60秒周期一次性结算25 `[C]`；
- 页面隐藏、关闭和重新打开后的离线资源结算；
- Schema v6本地自动存档、旧版迁移、手动保存、JSON导入与导出；
- 结构化基础事件记录；
- 原体编辑、军团制造、领土地图、远征、战斗与奖励闭环；
- 固定底部亚空间终端，支持快捷指令、普通喊话和“聆听”；
- “空间状态”SVG、响应式状态动画，以及可在Lilith与沃达连之间切换的“当前在线”；
- 支持点击交谈与`/交谈 Lilith／沃达连 [内容]`关键词回应；
- 新游戏六段封印叙事与妖精女皇宣战演出；
- 封印终端、血潮裂隙、虚空观测、遗迹琥珀四套持久化配色；
- 鼠标、触屏和数字键 `1`～`8` 页面切换；
- 390×844 与 1366×768 浏览器布局验证。

资源、时钟与存档由独立规则模块负责，界面不直接修改权威游戏状态。
